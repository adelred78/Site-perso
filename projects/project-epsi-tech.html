EPSI Tech – Plateforme E-commerce Informatique

Projet transversal réalisé à l’EPSI Paris. Repris et amélioré individuellement pour optimiser le code et finaliser l’interface utilisateur.

Auteur

Adel Redjemi

Technologies

PHP, HTML5, CSS3, JavaScript

Base de données & Outils

MySQL, XAMPP, VS Code, phpMyAdmin

🎯 Présentation

EPSI Tech est une boutique en ligne spécialisée dans la vente de matériel informatique.

Le site permet aux utilisateurs de parcourir plusieurs catégories de produits :

  • ordinateurs de bureau
  • ordinateurs portables
  • téléphones

👤 Mon rôle

  • Design & Frontend : Création de l’identité visuelle inspirée de l’EPSI et intégration des pages principales du site.
  • Base de données : Conception et gestion de la base MySQL via phpMyAdmin.
  • Backend : Développement des fonctionnalités d’authentification et gestion dynamique du panier.

⚙️ Fonctionnalités principales

  • Gestion utilisateur : inscription et connexion sécurisée avec hachage des mots de passe
  • Catalogue dynamique : affichage des produits par catégorie
  • Panier interactif : ajout d’articles, modification des quantités, calcul automatique du total
  • Commandes : enregistrement des commandes dans la base de données

🗄️ Stack technique

  • Langages : PHP, HTML5, CSS3, JavaScript
  • Base de données : MySQL via XAMPP
  • Outils : VS Code, phpMyAdmin

📊 Structure de la base de données

  • users : gestion des comptes utilisateurs
  • article : gestion des produits, prix et images
  • commandes : historique des achats
