🎯 Présentation du Projet

Dans le cadre du projet transversal EPSI 2025, nous avons développé un site e-commerce complet pour la vente de vélos SmartBike. Ce projet nous a permis d'acquérir une expérience concrète en développement web full-stack, de la conception de la base de données à l'interface utilisateur.

L'objectif principal était de créer une plateforme fonctionnelle permettant aux utilisateurs de parcourir un catalogue de vélos intelligents, de s'inscrire, de se connecter et de passer des commandes en ligne de manière sécurisée.

⚙️ Fonctionnalités Développées

  • Système d'Inscription et Connexion : Création de comptes utilisateurs avec validation et authentification sécurisée.
  • Catalogue Produits : Affichage dynamique des vélos SmartBike avec descriptions détaillées, prix et images.
  • Panier et Commandes : Gestion complète du panier d'achat et processus de commande intégré.
  • Espace Administrateur : Interface backend pour la gestion des produits et des commandes.

🗄️ Architecture Technique

Le projet a été structuré selon une architecture MVC (Modèle-Vue-Contrôleur) pour garantir la maintenabilité et la scalabilité du code :

  • Frontend : HTML5 sémantique pour la structure, CSS3 pour le design responsive et JavaScript pour les interactions dynamiques.
  • Backend : PHP 8 pour la logique serveur avec une architecture MVC claire séparant les responsabilités.
  • Base de Données : MySQL avec conception réalisée via Looping (MCD/MLD), gestion via phpMyAdmin.
  • Environnement : XAMPP pour le serveur Apache et MySQL en local.

📊 Conception de la Base de Données

Nous avons utilisé Looping pour modéliser notre base de données avec un Modèle Conceptuel de Données (MCD) et un Modèle Logique de Données (MLD). La base comprend plusieurs tables interconnectées :

  • Table utilisateurs : Gestion des comptes clients
  • Table produits : Catalogue des vélos SmartBike
  • Table commandes : Historique des achats
  • Table lignes_commande : Détails des produits commandés
