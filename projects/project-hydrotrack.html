HydroTrack – Plateforme IoT d’Arrosage Intelligent

Projet académique réalisé dans le cadre du Bachelor Informatique à l’EPSI Paris.

Auteur

Adel Redjemi

Technologies

HTML, CSS, JS, Node-RED, Supabase

IoT & API

ESP32, OpenWeather API

🎯 Présentation du Projet

HydroTrack est une plateforme IoT permettant de surveiller l’humidité du sol et d’assister l’utilisateur dans l’arrosage manuel grâce à des notifications intelligentes. Le système repose sur un capteur d’humidité connecté à un ESP32 qui envoie les données vers une plateforme web.

⚙️ Architecture

  • Capteur d’humidité
  • ->
  • ESP32
  • ->
  • Node-RED (logique et API)
  • ->
  • OpenWeather API
  • ->
  • Supabase (base de données)
  • ->
  • Interface Web HydroTrack

⚙️ Fonctionnalités principales

Dashboard

  • affichage de l’humidité actuelle
  • affichage de la météo
  • statut d’arrosage

Historique

  • suivi des mesures d’humidité
  • évolution des données

Paramètres

  • modification du seuil d’humidité
  • activation / désactivation des notifications

📊 Logique d’alerte

3 états possibles :

  • Humidité correcte : humidité ≥ seuil
  • Temps d’arroser : humidité < seuil et pas de pluie
  • Pluie détectée : humidité < seuil et pluie détectée

🗄️ Technologies utilisées

  • Frontend : HTML, CSS, JavaScript
  • Backend : Node-RED
  • Base de données : Supabase (PostgreSQL)
  • IoT : ESP32, Capteur d’humidité
  • API externe : OpenWeather API
